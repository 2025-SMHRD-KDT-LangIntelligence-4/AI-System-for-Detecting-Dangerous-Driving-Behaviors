# ZeroAccident

> CCTV 영상 기반 AI 위험 상황 탐지 및 안전관리 시스템

## 1. 프로젝트 소개

ZeroAccident는 작업 현장의 CCTV 영상을 분석해 위험 상황을 실시간으로 탐지하고 안전사고를 예방하는 AI 안전관리 시스템입니다.

딥러닝 기반 객체 탐지 모델로 현장의 위험 요소를 파악하며, 이 데이터를 서버로 연동해 웹에서 직관적으로 모니터링할 수 있도록 개발했습니다. AI 영상 분석 기술과 웹 애플리케이션을 결합해, 실제 산업 현장에 적용할 수 있는 실용적인 서비스를 구축하는 데 집중했습니다.

### 프로젝트 목표

* CCTV 영상 내 위험 요소 자동 탐지
* AI 분석 모델과 웹 애플리케이션 연동
* 탐지 데이터의 체계적인 DB 저장 및 관리
* 관리자용 모니터링 대시보드 구축
* 실제 서비스 도입을 고려한 서버 및 데이터 파이프라인 설계

---

## 2. 개발 배경

산업 현장의 안전사고를 막으려면 위험 상황을 빠르게 인지하고 대처하는 것이 가장 중요합니다. 하지만 사람이 수많은 CCTV 영상을 24시간 내내 주시하는 것은 현실적으로 한계가 있고 피로도도 높습니다.

이런 문제를 해결하고자, 사람이 직접 화면을 계속 모니터링하지 않아도 AI가 알아서 위험 요소를 찾아내 관리자에게 알려주는 시스템을 기획했습니다. 관리자는 시스템이 필터링해준 위험 상황만 집중적으로 확인하면 되므로 모니터링 효율을 크게 높일 수 있습니다.

---

## 3. 주요 기능

### 3.1 CCTV 영상 기반 객체 탐지

YOLO 모델을 이용해 CCTV 영상 속 객체를 식별합니다. 모델이 지정된 위험 객체나 상황을 인식하면 그 결과를 안전관리 시스템으로 넘겨주도록 구성했습니다.

### 3.2 AI 분석 결과 관리

AI가 분석한 이벤트 데이터를 DB에 저장하고, 서버와 연동해 기록을 관리합니다. 이 데이터는 이후 관리자가 웹 화면에서 손쉽게 열람할 수 있습니다.

### 3.3 안전관리 정보 조회

관리자가 웹 브라우저를 통해 언제든 누적된 안전 데이터와 탐지 이력을 조회할 수 있습니다. DB에 쌓인 정보를 실시간으로 화면에 렌더링하도록 구현했습니다.

### 3.4 데이터 관리

MyBatis와 MySQL을 사용해 사용자 정보와 시스템 로그 데이터를 안정적으로 처리하고 관리합니다.

## 8. Trouble Shooting

개발 과정에서 마주친 주요 문제들과 이를 해결해 나간 과정입니다.

### 8.1 대용량 데이터셋을 활용한 AI 모델 학습 환경 문제

#### 문제 상황

YOLO 모델에 대규모 데이터셋을 넣어 학습시키는 도중, 시스템 리소스가 부족해지며 다음과 같은 에러가 발생했습니다.
`OSError: [WinError 1455] The paging file is too small for this operation to complete.`

#### 원인 분석

학습 시 GPU VRAM뿐만 아니라 시스템 RAM과 Windows 가상 메모리(페이징 파일)까지 한계치에 도달하는 것을 확인했습니다. Batch Size가 너무 크거나 캐싱 옵션이 시스템에 과도한 부하를 주고 있었습니다.

#### 해결 과정

PC 하드웨어 환경에 맞춰 Batch Size를 하향 조정하고, 데이터 캐싱 옵션을 해제했습니다. 또한 Windows 가상 메모리 할당량을 넉넉하게 늘려 리소스 부족 현상을 완화했습니다.

#### 결과

메모리 초과 에러가 사라졌고, 제한된 하드웨어 스펙 내에서도 무사히 모델 학습을 마칠 수 있었습니다.

---

### 8.2 대규모 데이터셋 관리

#### 문제 상황

학습에 필요한 CCTV 영상 및 이미지 데이터셋 용량이 너무 커서, 이를 한 폴더에 넣고 다루려다 보니 디스크 읽기 속도에 병목이 생겼습니다.

#### 해결 과정

데이터를 한 번에 메모리에 올리지 않고, 성격과 용도에 맞춰 여러 디렉토리 단위로 분할했습니다. 또한 필요한 데이터만 순차적으로 로드해 학습하도록 파이프라인을 조정했습니다.

#### 결과

한 번에 처리해야 하는 I/O 부담이 줄어들어, 로컬 PC 환경에서도 대규모 데이터를 무리 없이 다루고 학습 속도를 안정화할 수 있었습니다.

## 9. 실행 방법

### 9.1 요구 환경

* Java
* Spring Boot
* MySQL
* Python
* YOLO 환경

### 9.2 Backend 실행

1. 프로젝트 소스 코드를 Clone 합니다.
2. MySQL에 zeroaccident (또는 지정한 DB명) 데이터베이스를 생성합니다.
3. application.properties 파일에서 데이터베이스 접속 정보(URL, Username, Password)를 환경에 맞게 수정합니다.
4. 제공된 DDL 스크립트를 실행해 테이블을 생성합니다.
5. Spring Boot 애플리케이션을 실행합니다.

### 9.3 AI 환경 실행

1. Python 가상 환경(venv 등)을 생성하고 활성화합니다.
2. requirements.txt를 통해 필요한 패키지를 설치합니다.
3. 학습된 YOLO 모델 가중치 파일(pt 파일 등)을 지정된 경로에 배치합니다.
4. Python 추론 스크립트를 실행해 웹 서버와 연동을 시작합니다.
