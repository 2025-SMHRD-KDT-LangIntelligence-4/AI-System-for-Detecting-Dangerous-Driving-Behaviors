# ZeroAccident

> **CCTV 영상 기반 AI 위험 상황 탐지 및 안전관리 시스템**

## 1. 프로젝트 소개

**ZeroAccident**는 CCTV 영상을 기반으로 작업 현장의 위험 상황을 탐지하고, 안전사고를 예방할 수 있도록 지원하는 **AI 기반 안전관리 시스템**입니다.

CCTV 영상에서 객체를 탐지하는 AI 모델을 활용하여 작업 현장의 위험 요소를 분석하고, 탐지 결과를 서버 및 데이터베이스와 연계하여 관리할 수 있도록 구현했습니다.

본 프로젝트를 통해 **웹 애플리케이션 개발과 AI 영상 분석을 결합한 안전관리 서비스**를 구축하는 것을 목표로 했습니다.

### 프로젝트 목표

* CCTV 영상 기반 위험 요소 탐지
* AI 모델과 웹 애플리케이션의 연계
* 탐지 결과의 데이터베이스 저장 및 관리
* 관리자가 위험 상황을 확인할 수 있는 웹 환경 구축
* 실제 서비스 환경을 고려한 서버 및 데이터 처리 구조 설계

---

## 2. 개발 배경

산업 현장에서 발생하는 안전사고를 예방하기 위해서는 위험 상황을 신속하게 발견하고 대응하는 것이 중요합니다.

그러나 CCTV를 사람이 지속적으로 모니터링하는 방식은 **24시간 실시간 감시의 한계와 인적 자원의 부담**이 존재합니다.

ZeroAccident는 이러한 문제를 해결하기 위한 방법으로 **AI 기반 영상 분석 기술을 활용하여 CCTV 영상에서 위험 요소를 자동으로 탐지**하고, 탐지 결과를 시스템에서 관리할 수 있도록 설계했습니다.

이를 통해 관리자가 모든 CCTV 영상을 직접 확인하지 않아도 AI가 탐지한 위험 상황을 중심으로 확인할 수 있도록 하는 것을 목표로 했습니다.

## 3. 주요 기능

### 3.1 CCTV 영상 기반 객체 탐지

CCTV 영상 데이터를 AI 모델에 입력하여 영상 내 객체를 탐지합니다.

YOLO 계열의 객체 탐지 모델을 활용하여 영상에서 지정된 객체를 식별하고, 탐지 결과를 안전관리 시스템에서 활용할 수 있도록 구성했습니다.

### 3.2 AI 분석 결과 관리

AI 모델을 통해 분석된 탐지 결과를 서버와 연계하여 관리할 수 있도록 구현했습니다.

탐지 결과를 데이터베이스에 저장하고, 웹 애플리케이션을 통해 관리자가 확인할 수 있도록 구성했습니다.

### 3.3 안전관리 정보 조회

관리자는 웹 화면을 통해 시스템에 저장된 안전 관련 정보를 확인할 수 있습니다.

서버에서 데이터베이스의 정보를 조회하고, 조회된 결과를 웹 화면에 전달하는 구조로 구현했습니다.

### 3.4 데이터 관리

사용자 및 안전관리와 관련된 데이터를 MySQL 데이터베이스에 저장하고 관리합니다.

MyBatis를 활용하여 SQL을 직접 작성하고 애플리케이션과 데이터베이스 간의 데이터 처리를 구현했습니다.

## 4. 시스템 아키텍처

ZeroAccident는 **웹 애플리케이션 영역과 AI 영상 분석 영역을 연계하는 구조**로 설계했습니다.

### 전체 구조

```text
                    ┌─────────────────┐
                    │   CCTV / 영상    │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │   AI 분석 영역   │
                    │     Python      │
                    │      YOLO       │
                    └────────┬────────┘
                             │
                       탐지 결과 전달
                             │
                             ▼
┌──────────────┐     ┌─────────────────┐
│    사용자     │────▶│   Spring Boot   │
│   Web Browser│◀────│     Server      │
└──────────────┘     └────────┬────────┘
                              │
                              ▼
                       ┌─────────────┐
                       │    MyBatis  │
                       └──────┬──────┘
                              │
                              ▼
                       ┌─────────────┐
                       │    MySQL    │
                       └─────────────┘
```

### 웹 애플리케이션 구조

```text
JSP
 │
 ▼
Controller
 │
 ▼
Service
 │
 ▼
MyBatis
 │
 ▼
MySQL
```

웹 애플리케이션은 Spring Boot를 기반으로 구성하고, 데이터베이스 접근에는 MyBatis를 사용했습니다.

JSP를 통해 사용자에게 웹 화면을 제공하며, Controller → Service → MyBatis의 계층 구조를 통해 요청을 처리하도록 구성했습니다.

## 8. Trouble Shooting

프로젝트 개발 과정에서 발생한 문제를 단순히 수정하는 데 그치지 않고, **원인을 분석한 후 해결 방법을 적용하는 방식으로 문제를 해결했습니다.**

### 8.1 대용량 데이터셋을 활용한 AI 모델 학습 환경 문제

#### 문제

YOLO 모델 학습 과정에서 대규모 데이터셋을 사용하면서 메모리 및 시스템 리소스 사용량이 증가했고, 학습 도중 다음과 같은 오류가 발생했습니다.

```text
OSError: [WinError 1455]
The paging file is too small for this operation to complete.
```

#### 원인 분석

학습 과정에서 GPU 메모리뿐만 아니라 시스템 메모리와 Windows의 가상 메모리까지 함께 사용되는 것을 확인했습니다.

특히 대규모 데이터셋을 학습하는 과정에서 Batch Size 및 데이터 캐싱 등의 설정이 시스템 리소스 사용량에 영향을 줄 수 있음을 확인했습니다.

#### 해결

학습 환경을 점검한 후 다음과 같은 설정을 조정했습니다.

* Batch Size 조정
* 데이터 캐싱 옵션 확인 및 조정
* Windows 가상 메모리 설정 점검
* 학습 과정에서 GPU 및 시스템 메모리 사용량 확인
* 대규모 데이터셋을 효율적으로 관리하기 위한 데이터 분할 검토

#### 결과

학습 과정에서 발생하는 메모리 사용량을 줄이고, 제한된 하드웨어 환경에서도 AI 모델 학습을 진행할 수 있도록 학습 환경을 조정했습니다.

---

### 8.2 대규모 데이터셋 관리

#### 문제

AI 모델 학습을 위해 대규모 CCTV 관련 데이터를 사용하면서 데이터셋 자체의 크기가 커졌고, 하나의 데이터셋을 그대로 관리하기에는 저장 및 처리 측면에서 부담이 발생했습니다.

#### 해결

대규모 데이터를 적절한 단위로 분할하여 관리하는 방식을 적용하고, 학습 환경의 하드웨어 사양을 고려하여 필요한 데이터만 단계적으로 활용할 수 있도록 구성했습니다.

#### 결과

대규모 데이터셋을 한 번에 처리해야 하는 부담을 줄이고, 제한된 환경에서도 데이터셋을 관리하고 학습할 수 있도록 개선했습니다.

## 9. 실행 방법

### 9.1 요구 환경

프로젝트 실행을 위해 다음과 같은 개발 환경을 사용했습니다.

```text
Java
Spring Boot
MyBatis
MySQL
Tomcat
Python
YOLO
```

### 9.2 Backend 실행

1. 프로젝트 소스 코드를 다운로드합니다.
2. MySQL 데이터베이스를 생성합니다.
3. 프로젝트의 데이터베이스 연결 정보를 환경에 맞게 설정합니다.
4. 필요한 테이블 및 초기 데이터를 구성합니다.
5. Spring Boot 애플리케이션을 실행합니다.

### 9.3 AI 환경 실행

1. Python 실행 환경을 구성합니다.
2. 필요한 Python 패키지를 설치합니다.
3. YOLO 모델 및 학습/추론에 필요한 데이터를 준비합니다.
4. AI 분석 프로그램을 실행합니다.
5. 분석 결과를 웹 애플리케이션에서 활용합니다.

### 9.4 데이터베이스 설정

프로젝트 실행 전 MySQL 데이터베이스 연결 정보를 프로젝트 환경에 맞게 설정해야 합니다.

```text
DB_HOST=
DB_PORT=
DB_NAME=
DB_USERNAME=
DB_PASSWORD=
```

> 실제 프로젝트의 설정 방식에 맞게 수정합니다.
> **비밀번호 및 API Key 등 민감한 정보는 GitHub에 업로드하지 않습니다.**
